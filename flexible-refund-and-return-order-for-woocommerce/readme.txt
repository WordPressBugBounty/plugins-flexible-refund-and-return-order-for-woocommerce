WooCommerce refund and returns process made simple. Let your customers request a refund and return products directly from the My Account page.

== Description ==

Flexible Refund for WooCommerce – EU One Click Return lets you manage customer refund and return requests directly in WooCommerce.

Customers can request a refund from My Account → Orders, complete a form, and follow the progress of their request. Store administrators can review submissions, add customer notes, change request statuses, and approve refunds from the order edit screen.

Use the form builder to collect return reasons, customer comments, and required confirmations. Add a link to your return policy in email notifications and customize the messages sent during the process.

The free version supports full-order refund requests. PRO adds partial refunds, guest forms, separate complaint and repair requests, conditional availability, and automation.

### Free Plugin Features

* Refund requests from My Account — let customers start a request from their order history.
* Full-order refund requests — customers submit all available product quantities for refund.
* Custom button label — change the text displayed on the refund request button.
* Refund form builder — collect the information you need to review a return.
* Five field types — Text, Textarea, Checkbox, Radio, and Select.
* Field settings — configure labels, descriptions, required answers, options, placeholders, and CSS classes.
* Text length settings — set minimum and maximum lengths for Text and Textarea answers.
* Drag-and-drop field ordering — arrange fields to match your return process.
* Policy confirmations — create required checkboxes for customers to acknowledge your return or privacy policy.
* Policy page links — select a policy page and include its link in request emails.
* Shipping cost refunds — exclude shipping, let the customer choose, or include it automatically.
* Request management in WooCommerce — review submitted products and customer answers from the order edit screen.
* Request statuses — manage Requested, Shipment, Verifying, Approved, Refused, and Canceled requests.
* Customer notes — explain decisions and provide instructions.
* Request cancellation — customers can use Cancel Request in My Account while a request is Requested or Verifying.
* Request history — keep completed requests and allow another eligible request after the active one ends.
* Email notifications — notify customers about submissions and status changes, and notify the administrator about new requests.
* Editable email content — customize messages with order and request placeholders.
* WooCommerce refunds — approving a refund request creates a WooCommerce refund. Payment gateway refunds depend on the gateway’s refund support.
* Stock restoration — the refund process asks WooCommerce to restock refunded product quantities.

Only one request can be active for an order at a time. Request submission, request approval, and payment reimbursement are separate steps unless PRO automatic approval is enabled.

Read the [plugin documentation](https://wpdesk.net/sk/flexible-refund-readme-docs) for configuration instructions.

== Installation ==

You can install the plugin like any other WordPress plugin.
1. Download and unzip the latest release of the plugin.
2. Upload the entire plugin directory to your /wp-content/plugins/ directory.
3. Activate the plugin through the Plugins menu in the WordPress Administration.

You can also use WordPress uploader to upload the plugin zip file in WordPress menu Plugins -> Add New -> Upload Plugin. You can find and install the plugin through your Plugins menu with a search bar too.

== Frequently Asked Questions ==

= How can I use this plugin to manage a WooCommerce refund? =

After installing the plugin, enable the refund button in the plugin settings. You may also add a refund form with fields for your customers like text, textarea, checkbox, radio, and select with description, CSS class, and additional field settings. You can describe your refund and return policy and show your customers additional information for the refund form.

Refund buttons will become visible for your customers on the My Account page of their accounts for their orders.

You will find refund requests in your WooCommerce -> Refund Request menu. You'll be able to send the message and decide about the refund (and change its status) in the Order Edit screen.

The customer will receive your notes and refund request status changes via automatic emails (that are customizable too). For example, you may add the refund requirements or further steps to follow by your customers.

So, the Flexible Refund for WooCommerce – EU One Click Return plugin will help you manage refund requests and communication with your customers!

= What are the differences between the Flexible Refund and the built-in WooCommerce refund options? =

By default, WooCommerce lets you process the refund manually. After you receive the call or an email from a customer, go to the *WooCommerce &rarr; Orders &rarr; Edit the order &rarr;* and use the Refund button below the product list.

If you want to speed up the refund and returns process and do not miss any calls or emails from your customers, use  Flexible Refund for WooCommerce – EU One Click Return. The plugin makes refund requests easier for your customers and yourself! You will manage all order refunds under the *WooCommerce &rarr; Orders* menu.

The plugin lets you add and customize the refund form, communicate with customers, and process the refund in WooCommerce!

= Can I allow customers to ask for a shipping costs refund? =

Yes. You can enable that option in the plugin settings. The plugin will allow your clients to ask for a refund for the whole order.

Customers can select specific items for a partial refund in the PRO version of the plugin.

= Can I use the plugin to cancel WooCommerce orders? =

The plugin lets your customers send you WooCommerce order refund requests much faster. They may also cancel such requests before your reply on the My Account page if they change their mind, or want to correct the refund request.

With the Flexible Refund for WooCommerce – EU One Click Return plugin, buyers may also cancel WooCommerce orders using the refund request button for an order before payment. You can add the information about the refund process on the separate page (Refund Policy or Terms &amp; Conditions), and in the refund form as well. In that case, of course, you will not have to give the money back.

If you want to cancel the WooCommerce orders automatically if buyers don't pay for them online, use the WooCommerce built-in settings. Go to *WooCommerce &rarr; Settings &rarr; Products &rarr; Inventory*, enable stock management, and choose the maximum time for the payment (Hold Stock). That will auto-cancel a WooCommerce order for you without the need to change something programmatically.

What's more, the plugin lets them check the refund status changes on their My Account pages, and thanks to the refund emails (you may customize them as well).

The store administrator will be able to manage all refunds, returns, and warranty requests in WooCommerce &rarr; Refund Requests tab. After the customer requests a refund for a WooCommerce order, the new section with refund info will appear in the specific order view.
